# remote-rocketship-mcp

An MCP (Model Context Protocol) server that exposes one tool, `search_remote_rocketship_jobs`, for querying job listings from [RemoteRocketship](https://www.remoterocketship.com).

## What it does

The server calls `POST https://www.remoterocketship.com/api/openclaw/jobs` with a Bearer token and returns the `jobOpenings` array from the response.

The tool accepts these optional filter parameters:

| Parameter          | Type       | Description                          |
| ------------------- | ---------- | ------------------------------------- |
| `jobTitleFilters`   | `string[]` | Job titles to filter by               |
| `locationFilters`   | `string[]` | Locations to filter by                |
| `seniorityFilters`  | `string[]` | Seniority levels to filter by         |
| `techStackFilters`  | `string[]` | Technologies to filter by             |
| `showRemoteJobs`    | `boolean`  | Only show remote jobs                 |
| `minSalaryFilter`   | `number`   | Minimum salary                        |
| `page`              | `number`   | Page number to fetch                  |
| `itemsPerPage`      | `number`   | Number of results per page            |

## Prerequisites

- Node.js 18+
- A RemoteRocketship API key

## Setup

1. Install dependencies:

   ```
   npm install
   ```

2. Create a `.env` file (or otherwise set the environment variable) with your API key:

   ```
   cp .env.example .env
   ```

   Then edit `.env` and set:

   ```
   RR_API_KEY=your_remoterocketship_api_key_here
   ```

3. Build the project:

   ```
   npm run build
   ```

   This compiles `src/index.ts` to `dist/index.js`.

## Running

- **Production build**: `npm start` (runs `dist/index.js`)
- **Dev mode** (no build step, runs TypeScript directly): `npm run dev`

The server communicates over stdio, per the MCP spec — it's meant to be launched by an MCP client, not run standalone in a terminal.

`RR_API_KEY` must be set in the environment the server process runs in. The server exits immediately with an error if it's missing.

## Connecting to an MCP client

### Claude Desktop

Add to your Claude Desktop config (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "remote-rocketship": {
      "command": "node",
      "args": ["/absolute/path/to/dist/index.js"],
      "env": {
        "RR_API_KEY": "your_remoterocketship_api_key_here"
      }
    }
  }
}
```

Restart Claude Desktop after editing the config. The `search_remote_rocketship_jobs` tool will then be available in conversations.

### Other MCP clients

Any MCP-compatible client that can launch a stdio server works the same way: point it at `node /absolute/path/to/dist/index.js` and ensure `RR_API_KEY` is set in that process's environment.
